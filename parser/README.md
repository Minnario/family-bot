# Eval парсера Family Assistant

## Запуск

```bash
pip install anthropic
export ANTHROPIC_API_KEY=sk-ant-...

python run_eval.py                 # все три модели
python run_eval.py --model haiku   # одна
```

## Файлы

| Файл | Что это |
|---|---|
| `parser_prompt.md`   | системный промпт, шаблон с `{{TODAY}}`, `{{WEEKDAY_RU}}`, `{{OPEN_TASKS}}` |
| `eval_dataset.json`  | 22 фразы с эталонным разбором |
| `run_eval.py`        | прогон, сравнение, точность и стоимость |

## Как читать вывод

```
Точность : 19/22  (86%)
Стоимость: $0.0143 за прогон  (~$0.19 за 300 сообщений)

Расхождения (3):
  #5  Глеб тренировка по футболу 6:30, среда
       проверяет: 6:30 с двоеточием → 18:30
       ✗ time_start: ждали '18:30', получили '06:30'
```

Строка `проверяет` показывает, какое правило не сработало. Правится промпт,
не датасет.

## Правила работы с датасетом

1. **Не удалять исходные 22 кейса** при расширении. Это регрессионная база.
2. **Не подгонять эталон под вывод модели.** Если модель разобрала иначе,
   а её вариант правильнее — сначала признать это осознанно, потом менять.
3. **Каждая реальная ошибка бота** добавляется сюда новым кейсом
   с правильным разбором.
4. Опорная дата `2026-09-03` (четверг) зафиксирована ради воспроизводимости.
   Менять её нельзя — поедут все ожидаемые даты.

## Что покрыто

Пять режимов времени · разрешение 12-часового формата (`6:30` → 18:30,
`3:00` → 15:00, `7 часов` → 19:00) · дедлайн против даты · три списка
(scheduled / backlog / daily) · размножение задачи на два имени ·
`assignee: null` при отсутствии имени · разговорный шум («после работы») ·
незнакомые слова («гелик») · перенос с сохранением времени.

## Чего НЕ покрыто (добавить позже)

Переспрос при часах 8–11 · закрытие задач («купил цемент») ·
отмена и пауза · время вне активных часов · опечатки и слитный ввод (`1930`).

Специально: сначала цифра на базовых случаях, потом расширение.

## Замечание про max_tokens

Скрипт проверяет `stop_reason == "max_tokens"` и помечает такой кейс отдельно.
Обрезанный `tool_use` — тихий сбой: ответ приходит, но неполный.
